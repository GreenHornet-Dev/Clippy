                    CLIPPY Q&A - QUICK START GUIDE
═══════════════════════════════════════════════════════════════════════════

OPEN THE APP:
  → Double-click: index-enhanced.html
  → Or drag index-enhanced.html into your browser

═══════════════════════════════════════════════════════════════════════════

THREE BUTTONS AT THE TOP:

  💬 CHAT - Ask questions
     Type a question → bot searches and answers
     
  📋 BROWSE - View all Q&A
     Filter by category, search, expand to see details
     
  ⚙️ ADMIN - Manage everything
     Add categories, add Q&A, export/import data

═══════════════════════════════════════════════════════════════════════════

QUICK TASKS:

1. ADD A NEW CATEGORY (Topic)
   → Click ⚙️ ADMIN
   → Enter category name (e.g., "Troubleshooting")
   → Enter emoji icon (e.g., 🐛)
   → Click ✅ Add Category

2. ADD A NEW Q&A ITEM
   → Click ⚙️ ADMIN
   → Select category dropdown
   → Enter Question
   → Enter Answer
   → Enter Description (optional)
   → Enter Key Phrases (comma-separated, e.g.: "install, setup, deploy")
   → Click ✅ Add Q&A Item

3. SEARCH ALL CONTENT
   → Type in search box
   → Searches: questions, answers, key phrases, descriptions
   → Real-time results

4. BACKUP YOUR DATA
   → Click ⚙️ ADMIN
   → Click ⬇️ Export Data
   → JSON file downloads
   → Save in safe location

5. RESTORE YOUR DATA
   → Click ⚙️ ADMIN
   → Click ⬆️ Import Data
   → Choose your JSON backup file
   → All data loads

═══════════════════════════════════════════════════════════════════════════

KEY PHRASES EXPLAINED:

Key phrases are searchable keywords that help the chatbot find answers.

EXAMPLE:
  Question: "How do I install the software?"
  Key Phrases: "install, setup, deploy, configure, begin, get started"
  
If someone asks "How do I set up this?", the bot will find this Q&A because
"setup" is in the key phrases!

═══════════════════════════════════════════════════════════════════════════

DESCRIPTION FIELD:

Add extra context about the Q&A. This is searchable!

EXAMPLE:
  Description: "Step-by-step guide for Windows, Mac, and Linux"
  
Someone searching "windows" would find this Q&A!

═══════════════════════════════════════════════════════════════════════════

TIPS FOR BEST RESULTS:

✓ Add synonyms in key phrases: "login, sign in, authenticate, access"
✓ Keep questions clear and specific
✓ Keep answers concise but complete
✓ Use descriptions for additional context
✓ Use emoji for category icons (makes it visual!)
✓ Export data every week as backup
✓ Test search as you add new items

TROUBLESHOOTING:

App won't load?
  → Make sure you're opening index-enhanced.html
  → Try a different browser (Chrome recommended)

Data disappeared?
  → You didn't save (export) your data
  → Export regularly to backup

Search not working?
  → Check spelling
  → Make sure key phrases are added
  → Try searching just part of a word

ADVANCED USERS (VS CODE):
